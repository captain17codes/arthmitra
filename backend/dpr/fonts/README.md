# DPR fonts

Noto Sans and Noto Sans Devanagari (Regular, Bold) from Google's Noto project,
licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).
Bundled so the DPR PDF renders Marathi (with HarfBuzz shaping via `uharfbuzz`)
and the ₹ sign identically on every host, including slim Docker images.
